
# YouTube Shorts Automation

An automated YouTube Shorts production and publishing project.

## Goals
- Discover interesting video topics.
- Generate original English scripts.
- Create voiceovers and visuals.
- Render vertical MP4 videos.
- Upload videos to YouTube automatically.

## Automation
GitHub Actions will run the production workflow in the cloud.

## Cost
The project is designed to use free services and free quotas where available. Paid services must not be used without approval.
